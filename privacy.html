นายแดงนายเขียวNAI DAENG NAI KHIAO

นโยบายความเป็นส่วนตัว

มีผลตั้งแต่ 25 ตุลาคม 2026 · ใช้กับแอปเผยแพร่คลิปสั้นของช่อง “นายแดงนายเขียว”

1. ขอบเขตของแอป

แอปนี้เป็นเครื่องมือภายใน ใช้งานโดยผู้ดูแลช่องเพียงคนเดียว บนคอมพิวเตอร์ส่วนตัว เพื่ออัปโหลดคลิปที่เราสร้างขึ้นเองไปยังบัญชีโซเชียลมีเดียของเราเอง (YouTube, Facebook, Instagram, TikTok) แอปไม่มีผู้ใช้ทั่วไป ไม่มีหน้าสมัครสมาชิก และไม่มีพื้นที่เก็บข้อมูลผู้ชม

2. ข้อมูลที่แอปเข้าถึง

  • ข้อมูลการอนุญาต (OAuth) — เมื่อผู้ดูแลช่องกดอนุญาตให้แอปโพสต์ แพลตฟอร์มจะออกโทเคนให้ (YouTube, Meta, TikTok) เราเก็บโทเคนเหล่านี้ไว้ในเครื่องเดียว ที่โฟลเดอร์ state/secrets/ เพื่อใช้เรียก API แทนการล็อกอินซ้ำ
  • ข้อมูลบัญชีขั้นต่ำ — รหัสเพจ Facebook, รหัสบัญชี Instagram และรหัสผู้ใช้ TikTok ที่จำเป็นต่อการระบุปลายทางการโพสต์
  • ไฟล์วิดีโอและคำบรรยาย — คลิปและข้อความที่เราเป็นเจ้าของ ใช้เฉพาะส่งขึ้นแพลตฟอร์มปลายทาง

เราไม่เก็บชื่อ อีเมล เบอร์โทร หรือข้อมูลส่วนบุคคลของผู้ชม และไม่อ่านข้อความ กล่องคอมเมนต์ หรือรายชื่อผู้ติดตามของบัญชีใด

3. วัตถุประสงค์การใช้ข้อมูล

ใช้เพื่อ (ก) อัปโหลด/ตั้งเวลาโพสต์คลิปของเราเอง (ข) ตรวจสถานะการเผยแพร่และสถิติพื้นฐานของโพสต์ของเราเอง และ (ค) แสดงสถานะการเชื่อมบัญชีในหน้าควบคุมภายในเครื่อง

4. การเปิดเผยข้อมูลต่อบุคคลที่สาม

แอปส่งข้อมูลเท่าที่จำเป็นไปยังแพลตฟอร์มที่คุณเชื่อมไว้โดยตรง ได้แก่ Google (YouTube Data API), Meta Platforms (Graph API) และ TikTok (Content Posting API) ตามนโยบายของแต่ละแพลตฟอร์ม เราไม่มีเซิร์ฟเวอร์กลาง ไม่ส่งข้อมูลไปยังบุคคลที่สามรายอื่น และไม่ขายหรือให้เช่าข้อมูล

5. การจัดเก็บและความปลอดภัย

  • โทเคนและรหัสแอปเก็บในเครื่องผู้ดูแลช่อง ไฟล์เหล่านี้ถูกกีดกันจาก Git (ไม่ถูกอัปขึ้นที่จัดเก็บโค้ดสาธารณะ)
  • หน้าควบคุมฟังเฉพาะ 127.0.0.1 (เครื่องเดียวกัน) ไม่เปิดให้เข้าจากอินเทอร์เน็ต และมีโทเคนป้องกันคำสั่งข้ามเว็บ
  • ไม่มีการส่งข้อมูลไปยังระบบวิเคราะห์ของเราเอง ไม่มีคุกกี้เพื่อการโฆษณา

6. ระยะเวลาการเก็บ

โทเคนจะถูกเก็บไว้จนกว่าจะตัดการเชื่อมต่อจากหน้าแอป หรือถูกเพิกถอนจากหน้าตั้งค่าความปลอดภัยของแพลตฟอร์มนั้น ไฟล์วิดีโอที่ประมวลผลแล้วจะถูกลบเมื่อพ้นรอบการเผยแพร่ตามที่ผู้ดูแลกำหนด

7. สิทธิของคุณ

คุณสามารถเพิกถอนสิทธิ์การเข้าถึงได้ทุกเมื่อที่หน้าการตั้งค่าของแต่ละแพลตฟอร์ม:

  • Google: myaccount.google.com/permissions
  • Meta: facebook.com/settings → Apps and Websites
  • TikTok: TikTok → Settings → Security → Manage app permissions

เมื่อเพิกถอนแล้ว แอปจะโพสต์แทนคุณไม่ได้อีก จนกว่าจะเชื่อมใหม่

8. เด็ก

แอปนี้ไม่ใช่บริการสำหรับเด็ก และไม่ได้มุ่งเก็บข้อมูลจากเด็กโดยเจตนา

9. การเปลี่ยนแปลงนโยบาย

หากมีการแก้ไขสาระสำคัญ เราจะปรับวันที่ “มีผลตั้งแต่” ด้านบนของหน้านี้
